3- mesh topology 
	each device is connected to every other device 
	number of cables =(D*(D-1))/2
	where D is the number of devices
	![[Pasted image 20261014142143.png]]
	redundancy meaning :having multiple alternative paths for data to travel between network nodes
	fault tolerance : because of redundancy Mesh topology is the most fault-tolerant network design because it features multiple redundant paths and direct interconnections between devices. If a single cable breaks, a node fails, or a router goes offline, the network automatically reroutes traffic through alternative functional paths without causing system downtime
